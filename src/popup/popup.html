Blipr

Blipr watches http and https pages. Open the page you want to watch, then click the Blipr icon again.

What to watch

Picking asks for access to this site, then closes this popup while you click the page. Open Blipr again and the selector is waiting.

Where it goes
Server
Custom title and message
How it fires

Cooldown is the shortest gap between two blips, in seconds. 0 blips on every change.

Reloading discards anything unsaved on the page, and Blipr never reloads the tab you are looking at.

    Blipr only watches the sites you allow. Saving asks for access to this one if you have not picked from it.
